# Runtime content foundation

Generate tables after changing libraries: `node tools/production/generate-content.mjs`. The command maps ContentDefinitions, AudioController and VFXController through Rojo. Existing Config.Audio / ImpactService positional sounds remain supported; avoid assigning duplicate sounds to both legacy and new playback hooks.

`StarterPlayer.StarterPlayerScripts.Controllers.AudioController` is a ModuleScript. `Audio.new()` creates/reuses PB_Master/SFX/Ambience/UI SoundGroups. `Play("flight.Wind", root, "owned-wind")` returns a Sound or a reason; `StopLoop("owned-wind")` stops it. Non-UI cues require a live BasePart/Attachment. It caps voices at48, flight loops at2/source, ambience at4/controller; unassigned cues remain silent. SetVolume accepts0–1; Destroy clears voices/connections. One controller per client is the intended budget owner. Owned experience IDs, mix and audible playback still require asset-production QA.

`Controllers.VFXController` is a ModuleScript. `VFX.new()` owns PB_LocalVFX; `Emit(name, position, payload)` returns success, and `Trail(name, root)` returns a stop function. SetReducedEffects reduces burst/trail density. All instances are non-colliding/non-queryable; recipes have distance, lifetime, concurrency and total cost caps. Destroy cancels tweens and clears instances/connections. Caller supplies server-confirmed outcome/location; never fire these methods to award gameplay. ScorePopup payload.Text is presentation text; existing UIController continues the authoritative score display.

These are reusable primitive renderers, not final bespoke art for every future feature. PoopSplat's shipped server path remains ImpactService.Splat for target-following welds. The local preview splat is a ground-normal primitive. Hatch/legendary/PvP/ability/cosmetic hooks can preview bursts or trails, but should not be wired to unimplemented backends. Replace recipe artwork under the same API after review.
